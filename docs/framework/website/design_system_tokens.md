# Public Website Design System Tokens

## Purpose

Define the shared visual primitives for the public website.

## Color Tokens

### Light Mode

- background: white or near white
- surface: light neutral
- border: soft gray
- text primary: near black
- text secondary: muted gray

### Dark Mode

- background: charcoal
- surface: dark neutral
- border: desaturated gray
- text primary: soft white
- text secondary: muted gray

## Spacing Tokens

- xs: 4
- sm: 8
- md: 16
- lg: 24
- xl: 32
- 2xl: 48
- 3xl: 64
- 4xl: 96
- 5xl: 120

## Typography Tokens

- hero headline
- section headline
- card title
- body large
- body default
- helper text

## Radius Tokens

- small
- medium
- large
- extra large
- pill

## Shadow Tokens

- subtle
- card
- elevated
- overlay

## Motion Tokens

- fast
- normal
- slow

## Usage Rules

1. Do not invent ad hoc spacing values if tokens already exist.
2. Use the same spacing rhythm across public pages.
3. Use the same typography hierarchy across public pages.
4. Theme tokens must map intentionally to dark and light mode.

## Final Principle

A token system is what keeps the site visually coherent across many pages and many iterations.
