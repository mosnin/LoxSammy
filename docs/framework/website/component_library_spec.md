# Public Website Component Library Specification

## Purpose

Define the reusable public site components so that all public pages feel cohesive and production ready.

## Core Components

- Header
- Announcement Bar
- Mega Menu
- Mobile Drawer
- Hero
- CTA Block
- Logo Marquee
- Case Study Card
- Stat Card
- Feature Split Section
- Pricing Card
- FAQ Accordion
- Testimonial Card
- Footer
- Blog Card
- Integration Card
- Form Block

## Shared Component Rules

1. Reuse components before creating new variations.
2. Keep border radius, spacing, typography, and shadow logic consistent.
3. Components must support light and dark mode.
4. Components must be responsive.
5. Components must support hover and focus states when interactive.

## Button Variants

- Primary
- Secondary
- Ghost
- Outline

## Card Variants

- Proof card
- Pricing card
- Testimonial card
- Feature card
- Blog card
- Integration card

## Forms

Public site forms may include:

- demo request
- contact
- newsletter
- waitlist

## Accessibility Requirements

- keyboard support
- visible focus states
- contrast compliance
- large enough tap targets on mobile

## Final Principle

A strong public component system reduces visual drift and makes the entire website feel engineered rather than assembled from random blocks.
